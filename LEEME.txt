CORRECCIÓN DEL MINUTO A MINUTO · EL TRIBUNO

Causa: el extractor leía únicamente /ttag/papa-leon-xiv-en-argentina,
pero las nuevas notas se publican bajo /ttag/el-papa-leon-xiv-en-la-argentina.

INSTALACIÓN:
1. Abrir el repositorio de GitHub > Code > scripts > update_news.py.
2. Pulsar el lápiz (Edit) y sustituir el contenido con el archivo incluido.
3. Guardar en main con Commit changes.
4. En Actions > Actualizar noticias de León XIV > Run workflow.
5. Verificar que data/latest.json tenga fecha updated_at reciente y cinco items.
6. Recargar el micrositio (Cmd+Shift+R) y comprobar los titulares.

Este parche NO reemplaza index.html, styles.css, agenda.js, visitas.js,
biografia.js, app.js ni el workflow de GitHub.

El script consulta ambas etiquetas, elimina duplicados por URL, lee las
fechas reales de las notas, ordena de más reciente a más antigua y publica
hasta cinco noticias. Si falla la obtención completa, conserva el JSON anterior.

GitHub Actions puede demorar; la página consulta el JSON cada 60 segundos,
pero la generación programada es aproximadamente cada 5 minutos.

OPCIONAL: más adelante cambiar los enlaces «Todas las noticias» y «Ver todas
las noticias» del index.html para apuntar a la etiqueta nueva.
