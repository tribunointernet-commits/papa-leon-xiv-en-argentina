# Actualización de portada — especial León XIV

Este ZIP contiene ÚNICAMENTE los archivos necesarios para poner el retrato aportado por la redacción en la portada. NO reemplaza el minuto a minuto.

Archivos para subir a la raíz del repositorio `papa-leon-xiv-en-argentina`:

- `index.html` (reemplazar el existente)
- `assets/styles.css` (reemplazar el existente)
- `assets/papa-leon-xiv-retrato.webp` (archivo nuevo)

## Pasos GitHub
1. Descomprimir el ZIP.
2. Abrir el repositorio en GitHub.
3. En **Code > Add file > Upload files**, arrastrar el contenido de la carpeta descomprimida conservando la ruta `assets/`.
4. Confirmar los cambios con **Commit changes**.
5. Abrir la URL pública y forzar recarga (Mac: Cmd + Shift + R).

**NO borrar ni reemplazar** `data/latest.json`, `assets/app.js`, `scripts/update_news.py`, `.github/workflows/actualizar-noticias.yml`, ni `requirements.txt`. Esos archivos sostienen la actualización automática de noticias.

Si la interfaz de GitHub no conserva carpetas al subir, actualizar individualmente `index.html`, editar `assets/styles.css` y subir `papa-leon-xiv-retrato.webp` dentro de `assets`.
